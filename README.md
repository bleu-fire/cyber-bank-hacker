# 💻 Cyber Bank Infiltration - Unity 3D Game Project

A low-poly retro cyberpunk drama game built with Unity & C#.

## 🎮 Game Concept
You play as an elite hacker infiltrating the high-security **MegaBank Cyber Vault**.
Evade security sweep lights, access terminal nodes, type hack commands, and breach the vault door before the security alert level reaches 100%!

## 🚀 How to Open & Run in Unity

1. Open **Unity Hub**.
2. Click **Add -> Add project from disk**.
3. Select this repository folder: `/home/bleufire/cyber-bank-hacker`.
4. Open the project with **Unity 2022.3 LTS** or **Unity 6000**.
5. Double-click `Assets/Scenes/CyberBank_Infiltration.unity` and press **Play ▶️**!
